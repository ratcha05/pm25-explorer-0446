# PM2.5 Explorer

ระบบสำรวจคุณภาพอากาศ PM2.5 ของประเทศไทย (รายวิชา 1145100 Data Science Toolbox)

## วิธีติดตั้ง
conda env create -f environment.yml

## ผู้จัดทำ
รัชชานนท์ รื่นจิตต์ 67114540446

## แหล่งข้อมูล

### Air4Thai API

- หน่วยงานเจ้าของข้อมูล: กรมควบคุมมลพิษ
- แหล่งข้อมูล: https://air4thai.pcd.go.th/
- API Endpoint: http://air4thai.pcd.go.th/services/getNewAQI_JSON.php
- รูปแบบข้อมูล: JSON
- ความถี่การอัปเดตข้อมูล: ประมาณรายชั่วโมง
- ประเภทข้อมูล: ข้อมูลสถานีตรวจวัดคุณภาพอากาศ เช่น PM2.5, PM10, O3, CO, NO2, SO2 และ AQI

### การตรวจสอบ robots.txt และเงื่อนไขการใช้ข้อมูล

- ตรวจสอบ URL `/robots.txt` แล้ว แต่เซิร์ฟเวอร์ไม่พบไฟล์ดังกล่าว (Not Found)
- ไม่สามารถใช้ผลนี้สรุปได้ว่าเว็บไซต์อนุญาตให้เข้าถึงข้อมูลโดยไม่มีข้อจำกัด
- บัญชีข้อมูลภาครัฐระบุชุดข้อมูลเป็นข้อมูลสาธารณะ แต่ยังไม่พบการระบุสัญญาอนุญาตใช้งานที่ชัดเจน
- โครงการนี้ใช้ข้อมูลเพื่อการศึกษาและอ้างอิงแหล่งข้อมูลจากกรมควบคุมมลพิษ
